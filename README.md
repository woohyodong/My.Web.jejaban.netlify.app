# 제자반 신앙생활

제자반 훈련용 모바일 중심 웹앱(PWA)입니다.
`42주 성경 1독`, `32주 암송`, `중보기도`를 한 사이트에서 사용할 수 있도록 구성되어 있습니다.

운영 대상:

- 제자반 훈련생
- 교회 성도
- 개인 신앙 루틴을 지속적으로 관리하려는 사용자

---

## 서비스 구성

### 1. 42주 성경 1독

- `42주 x 7일` 읽기표 제공
- 주차/일차 단위 진행 관리
- 완료 체크 및 다음 미완료 분량 이동
- 성경 본문 모달 보기
- GOODTV 오디오 재생 지원

### 2. 32주 암송

- 주차별 2개 암송 구절 제공
- 이전/현재/다음 주 이동
- 완료 체크 및 진행률 관리
- TTS 반복 재생 지원

### 3. 중보기도

- 기도제목 작성, 수정, 삭제
- 순서 이동
- 잠금 기도문 관리
- 브라우저 저장 기반 개인 관리

---

## 주요 특징

- 로그인 없이 바로 사용 가능
- Netlify 같은 정적 호스팅 환경에 배포 가능
- `localStorage` 기반 개인 진도 저장
- 모바일 홈 화면 설치 가능
- 일부 오프라인 사용 가능

## 데이터 파일

### `memorize/data.json`

- `32주 암송` 데이터
- 주차별 2개 구절 구조 사용

### `bible-read/data.json`

- `42주 성경 1독` 데이터
- 현재 `weeks -> days -> readings` 구조 사용

예시:

```json
{
  "planName": "42주 성경 1독",
  "totalWeeks": 42,
  "daysPerWeek": 7,
  "weeks": [
    {
      "week": 1,
      "days": [
        {
          "day": 1,
          "entry": 1,
          "readings": ["창1", "마1", "스1", "행1"]
        }
      ]
    }
  ]
}
```

## 실행 및 배포

정적 사이트이므로 별도 빌드 없이 바로 배포할 수 있습니다.

예상 배포 환경:

- Netlify
- 정적 파일 호스팅
- IIS 정적 사이트

로컬 확인 시에는 정적 서버로 루트를 열어 테스트하는 것을 권장합니다.

---

## 저장 방식

사용자 진행 상태와 기도문은 브라우저에 저장됩니다.

- 암송 완료 상태: `localStorage`
- 성경 읽기 진행 상태: `localStorage`
- 기도문 목록: `localStorage`

주의:

- 브라우저 데이터를 삭제하면 기록이 사라질 수 있습니다.
- 기기 간 자동 동기화는 지원하지 않습니다.

---

## 현재 상태와 주의사항

현재 사이트는 서비스 가능한 상태로 구성되어 있습니다.

다만 `42주 성경 1독` 데이터는 첨부된 제자반 읽기표 JPG를 완전 수기 검수한 최종판이 아니라,
기존 읽기 데이터를 `42주 x 7일` 구조로 변환한 버전입니다.

즉, UI와 기능은 동작하지만 실제 제자반 읽기표와의 최종 대조 검수는 추가로 필요합니다.
